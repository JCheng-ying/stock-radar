# Stock Radar · 产业链信息处理器

按"五个面"整理美股五大板块（AI / 量子计算 / 机器人 / 航空航天 / 自动驾驶）的信息，生成一个
自包含的静态网页，并在情况发生变化时推送到手机。个人研究用，不构成投资建议，没有任何下单功能。

| 面 | 看什么 | 数据从哪来 |
|---|---|---|
| 产业面 | 需求、供给、资本开支、技术进步、产业政策；公司在产业链的位置 | `data/chains/*.json`（人工整理的知识库）+ Summizer 图谱 |
| 基本面 | 收入、毛利率、EBITDA 利润率、EPS、自由现金流、RPO | Yahoo Finance 季报、SEC XBRL |
| 预期面 | 现价与一致目标价的差距、盈利预测 90 天修正、财报超预期幅度 | Yahoo Finance 一致预期 |
| 资金面 | 美债收益率 / 美元 / 信用利差（以年为周期）、板块 ETF 资金流、个股估值 | Yahoo Finance |
| 情绪面 | VIX、恐贪指数、估值拥挤度、杠杆 ETF 成交占比 → 具体点位 | Yahoo Finance、CNN |

## 网页里有什么

- **总览**：资金面、情绪面、五大板块 × 三浪的位置矩阵、IGV 分化上涨检查、板块资金流、点位信号、财报日历。
- **板块页**：产业面五项 → 三浪各自的六项验证 → 产业链图（点任一环节看公司、上下游关系、
  "⚙ 决定效率"和"▲ 主升浪触发点"）→ 产业消息。
- **公司详情**（点任何一行）：五个面各一张卡片，每个分数下面列出依据；季度图表、目标价区间、
  SEC 8-K 重大事件、新闻、Summizer 图谱关系。
- **全部公司**：可排序、按板块和信号筛选。
- **推送记录**：发过的每一条通知。

## 浪的位置怎么判断

每个板块的公司按所在环节分成三浪：一浪基础设备 → 二浪 B 端应用 → 三浪 C 端应用。每一浪用六项检查：

价格两项：篮子近 3 个月相对标普 500 的强度、站上 50 日线的公司占比。
财报四项：收入增速中位数、毛利率改善的公司占比（产品力）、EBITDA 利润率改善的公司占比
（经营效率）、RPO 同比增速中位数（长期大单）。

再结合过去一年的涨幅，分成：尚未启动 / 财报已改善价格未反映 / 价格先行财报待验证 / 启动初期 /
主升浪进行中 / 主升浪中的整理 / 回调中 / 过热。另外单独检查 IGV（软件 ETF）是不是"有分化的上涨"。

标了 ◦ 的公司（比如量子板块里的微软）业务多元，这个板块只占它一小部分——照常展示，但不计入浪位统计。

## 点位信号

`情绪热度`（0 极度悲观 ~ 100 极度乐观）由 RSI、52 周区间位置、偏离 200 日线合成。

- **关注买点**：基本面 ≥ 60、预期面 ≥ 58、热度 ≤ 38——好公司处在悲观区，利空大概率已定价。
- **回调风险**：热度 ≥ 80——利好大概率已被消化。
- 其余：观察 / 趋势中 / 中性 / 谨慎 / 弱势。

全部是写死在 `src/analyze.py` 里的规则，阈值可以改。

## 使用

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
./run.sh              # 刷新一次（首次约 2~4 分钟，之后有缓存）
open index.html
```

其它用法：`./run.sh --no-push`（只刷新网页）、`python -m src.main --force`（忽略缓存）、
`python -m src.main --rebuild`（不联网，用上次数据重新生成网页）。

### 手机推送

1. 手机装 [ntfy](https://ntfy.sh) App，订阅一个自己起的、随机一点的 topic（名字相当于密码）。
2. `cp .env.example .env`，把同一个名字填到 `NTFY_TOPIC=`。

不填就只记录到网页的「推送记录」，不发手机。会推送：新财报落地、进入关注买点 / 回调风险、
浪位变化、VIX 或市场情绪进入极端区、IGV 分化上涨信号变化、三天内的财报日、单日涨跌超 8%。
只在"和上一次相比发生了变化"时才发，财报季单次最多 12 条，其余合并成一条。

### 定时任务

```bash
./schedule/install.sh             # 工作日 06:45 / 13:20 / 17:30 自动跑 run.sh
./schedule/install.sh --uninstall
```

### 发布到 GitHub Pages（手机随时能看）

新建一个 GitHub 仓库，`git remote add origin <地址>`，在仓库 Settings → Pages 里选从 main 分支
根目录发布。之后 `run.sh` 每次刷新完会自动提交并推送。把网址填到 `.env` 的 `SITE_URL=`，
推送通知点开就直接跳到网页。注意仓库如果是公开的，网页任何人都能看到。

## 已知局限

- Yahoo Finance 的季报只有最近 5 个季度，所以同比只能算最新一个季度；一致预期和财报数据偶尔有
  口径不一致（比如 GAAP 与非 GAAP 混用导致"超预期 80%"这类异常值），打分时已做截断。
- RPO 只有按美国会计准则披露的公司才有（台积电、ASML 等外国公司没有）。
- FINRA 融资余额网站挡爬虫，杠杆风险用"三倍做多 ETF 成交额占比"代替；融资余额可手动写进 `notes.json`。
- 产业链知识库是人工整理的，不可能真的穷尽"全部公司"，需要按 `REFRESH_INSTRUCTIONS.md` 定期维护。
- SEC 接口要求请求头带联系邮箱，默认值是占位符，建议在 `.env` 里设置 `SEC_UA`。
